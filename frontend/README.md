# NeuroSync frontend
React + Vite app built from the supplied design files. See the root [README](../README.md).

`npm install` · `npm run dev` (http://localhost:5173) · `npm run build` · `npm test`

Copy `.env.example` to `.env` only if your backend is not at http://localhost:4000. The accessibility engine is imported from `../extension/content` (alias `@ext`) so the Reading Studio preview and the Chrome extension run the same code.
